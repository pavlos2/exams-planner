=== Exams Planner ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.9.80
License: GPLv2 or later

Δήλωση διαγωνισμάτων ανά τμήμα με αυτόματο έλεγχο κανόνων. Προσοχή: η ΔΙΑΓΡΑΦΗ του πρόσθετου σβήνει ΟΛΑ τα δεδομένα (δηλώσεις, ιστορικό, ρυθμίσεις). Η απενεργοποίηση και η αναβάθμιση όχι.

== Εγκατάσταση ==
1. Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση πρόσθετου → exams-planner.zip → Εγκατάσταση → Ενεργοποίηση.
2. Στο μενού «Exams Planner» ελέγξτε τμήματα, μαθήματα, αργίες και σημειώστε τον κωδικό καθηγητών.
3. Δημιουργήστε μια σελίδα και γράψτε μέσα της: [examsplanner]
4. Στείλτε στους συναδέλφους τη διεύθυνση της σελίδας και τον κωδικό.

== Σημειώσεις ==
* Η απενεργοποίηση κρατά τις δηλώσεις. Η διαγραφή του πρόσθετου τις σβήνει οριστικά.
* Αν η ιστοσελίδα χρησιμοποιεί πρόσθετο cache, εξαιρέστε τη σελίδα του προγράμματος από την cache (το όνομά της φαίνεται στην κορυφή των Ρυθμίσεων), ώστε να εμφανίζεται πάντα η σωστή ημερομηνία και η τρέχουσα έκδοση.
